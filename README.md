**Specification of the contents of the respective files**

* ALL\_SG1tm5\_CLUSTERdrug\_weka\_EV37difficult.arff: weka data file selected test set
* ALL\_SG1tm5\_CLUSTERdrug\_weka\_IV33.arff: weka data file test set
* ALL\_SG1tm5\_CLUSTERdrug\_weka\_training.arff: weka data file training set
* Dataset1.csv: excel data file training
* Dataset2plusclassifierresults.csv: excel data file test set
* Dataset3.csv: excel data file selected test set
* Dataset3\_SG3ADR1\_Logistic\_4levelLLM.dat: dat data file (output by SPSS) of the 4 level data for logistic regression as classifier: SG3ADR1 is the selection variable within SPSS selecting the SG3 (Disorders) as well as ADR1 (=DILI) variables in order to collect the generated probabilities
* DILI\_4LEVELSVMlogit\_06052025.dat: dat data file (output by SPSS) of the 4 level data for SVM as classifier
* Kort-Basic 4 level model RV\_02062026: short explanation of the simplest 4-Level model as a pedagogical example
* MLPmodeltrainingALLSG\_vrij15mrt2024.model: MLP classifier generated model on training set
* RFmodeltrainingALLSG\_vrij15mrt2024.model: RF classifier generated model on training set
* SimpleLogmodeltrainingALLSG\_vrij15mrt2024.model: Simple Logistic classifier generated model on training set
* SVMmodeltrainingALLSG\_vrij15mrt2024.model: SVM classifier generated model on training set
* Syntax\_4levelSVM\_rvWOE9april2025.sps: syntax to be used for generating the probabilities by the SVM classifier (use the respective SPSS dataset)
* Syntax\_logitandodds\_CLASSIFICATION\_usinglist drugs and probabilities\_spss\_SG3ADR1selectionvariable.sps: syntax to be used
* Syntax\_logitandodds\_ROCspss\_SG3ADR1selectionvariable.sps.
